# MedTrace — frontend-демонстрация

Интерактивный макет интерфейса прослеживаемости партий медицинских изделий. Он показывает маршрут от партии сырья через производство и контроль качества до отгрузки покупателю.

**Это демонстрация дизайна и сценариев.** Входа, API, базы данных и серверного хранения здесь нет. Все записи вымышлены и включены в клиентскую сборку. Поиск и переходы работают по этим данным; изменения в интерфейсе не сохраняются. Для реального учёта партий используйте отдельную серверную версию MedTrace.

## Запуск

Требуется Node.js 20.9+ и npm.

```bash
npm ci
npm run dev
```

Откройте `http://127.0.0.1:3000`.

## Статическая сборка

```bash
npm run lint
npm test
npm run build
```

Готовый сайт находится в `out/`. Его можно разместить на любом статическом хостинге. Для локального просмотра экспорта:

```bash
python3 -m http.server 8080 --bind 127.0.0.1 --directory out
```

Откройте `http://127.0.0.1:8080`.

## Что доступно в демо

- Рабочий стол и навигация по разделам.
- Таблицы партий, приёмок, качества, производства, остатков и отгрузок.
- Поиск партии и карта связей по заранее подготовленным примерам.
- Карточки записей, клиентские CSV-отчёты и адаптивный интерфейс.

Данные лежат в `src/data/demo.json` и `src/data/traces.json`. Для проверки статического режима нет необходимости настраивать переменные окружения или учётные записи.

## Ограничения

Нельзя создавать, редактировать, подтверждать или отправлять записи. CSV содержит только вымышленные данные из сборки. Этот вариант не обеспечивает контроль доступа, аудит или правила выпуска медицинских изделий и не предназначен для производственной эксплуатации.
