# Показ MedTrace с ноутбука

Для локальной демонстрации Supabase не нужен. ZIP содержит исходный код и вымышленные данные для заполнения; после запуска будет создана отдельная база на вашем ноутбуке.

1. Установите Node.js 20 или новее и распакуйте архив.
2. Откройте терминал в папке `MedTrace` и выполните `npm ci`.
3. Создайте `.env.local` из `.env.example`: на macOS/Linux — `cp .env.example .env.local`, в PowerShell — `Copy-Item .env.example .env.local`.
4. Выполните `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"` и замените строку `replace-with-a-long-random-secret` в `.env.local` полученным значением.
5. Выполните `npm run db:seed`, затем `npm run dev`. Откройте `http://localhost:3000`.

Демо-вход: `admin@medtrace.demo` / `MedTrace2026!`. Не запускайте эту учётную запись на общедоступном сервере. Проверьте весь сценарий на своём ноутбуке заранее: вход, карточку партии, граф прослеживаемости и скачивание CSV. Если порт 3000 занят, освободите его перед показом.

Папки `data/` и `private-uploads/` создаются локально и не входят в ZIP. Чтобы перенести уже созданные записи между компьютерами, копируйте их после полной остановки приложения. Подробности — в `README.md`.
